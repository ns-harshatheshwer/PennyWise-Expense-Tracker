PennyWise Object-Oriented Architecture

A comprehensive demonstration of Object-Oriented Programming (OOP) design principles implemented in genuine Python source files. Business logic, financial calculations, data encapsulation, and database abstractions are strictly decoupled from the web delivery layer.

1. Abstraction

Implemented via BaseTransaction(ABC) in models/transaction.py. Declares abstract contract methods: to_dict(), calculate_monthly_impact(), summary(), and validate().

from abc import ABC, abstractmethod

2. Encapsulation

Protected instance attributes (e.g. _amount, _title, _date) accessed exclusively via validated @property getters and setters. Ensures amounts are strictly > $0 and dates conform to ISO YYYY-MM-DD.

@property / @amount.setter

3. Inheritance

Expense inherits from Transaction, and RecurringExpense inherits from Expense. Child classes invoke super().__init__() and extend baseline functionality with categorization and recurrence frequency.

class Expense(Transaction):

4. Polymorphism

Subclasses override to_dict(), summary(), and calculate_monthly_impact(). ExpenseManager treats collections of transaction objects uniformly while each executes its specialized calculation.

def summary(self) -> str:

5. Composition

ExpenseManager possesses a DatabaseManager and aggregates Budget, Category, and Expense instances to perform high-level budgeting, analytics, and CSV export.

self._db = DatabaseManager()

6. Database Persistence

DatabaseManager isolates SQLite3 connection pooling, SQL queries, schema creation, transactions, and hydration of database rows directly into strongly typed OOP instances.

class DatabaseManager:
